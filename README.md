# Money Planner

PWA statik (tiada build) untuk rekod belanja & pendapatan dalam RM. Data disimpan dalam telefon (localStorage) dan berfungsi offline.

Live: https://michelleclairea22-ai.github.io/money-planner/

Ciri: Rekod (keypad kalkulator), Kalendar, Akaun & pindahan, Kategori, Analisis (donut), Bajet bulanan.

Segerak Google Sheet (pilihan): lihat arahan di atas `apps-script/Code.gs`, kemudian isi URL Web App dan kunci di tab Lagi > Tetapan.

Ujian: `node --test tests/`
